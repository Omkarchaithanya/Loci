WatchChange Mesh is not a simple chatbot; it is a human-approved disaster-coordination decision-support system. ### 1. CORE OBJECTIVE
Transform the existing MVP into a production-grade, permanent web application that demonstrates "Graph-Native Intelligence." You must prove that the system's intelligence is derived from multi-hop graph traversals and temporal state reconstruction, not just LLM text generation.

### 2. TECHNICAL PILLARS
You must implement the following advanced architectural patterns:
- Graph-Native RAG: Use FalkorDB for structured retrieval (hazard → zone → need → shelter → route). Avoid using vector similarity as the final authority for operational facts.
- Bi-Temporal Memory: Implement "Valid Time" (when a fact was true in the world) and "Observation Time" (when the system learned it). Use a `SUPERSEDES` relationship model to ensure history is never overwritten, only superseded.
- Multi-Agent Coordination: Build a bounded workflow consisting of an Ingestor, Outgoing Watch, Incoming Watch, Planner, Reviewer, and Coordinator.
- Human-in-the-Loop: Every AI-proposed action must be explicitly marked as "PROPOSED" and require a human "APPROVED" state before being committed to the operational graph.

### Product promise

WatchChange Mesh helps an incoming disaster-response watch understand what changed, what the previous watch tried, which work remains unresolved, and why the next operational recommendation is trustworthy.

It combines:

1. **Crisis Mesh** — hazards, zones, households, needs, shelters, agencies, assets, roads, constraints, and operational decisions.

1. **WatchChange** — temporal facts, supersession, episodes, failed attempts, open loops, handoffs, decisions, outcomes, and agent continuity.

The website must make the following concept obvious within the first minute:

> The system does not merely answer a question. It reconstructs the world at a previous time, compares it with the current world, identifies what changed, and proposes a human-reviewable action supported by a graph path and source evidence.
